# BookVibe — Читательский дневник

Мобильное PWA-приложение на русском языке для ведения читательского дневника.  
**Stack:** React + Vite (frontend) · Express 5 (backend) · PostgreSQL + Drizzle ORM · pnpm monorepo

---

## Что было сделано за сессию

### Аутентификация
- Регистрация по email + код подтверждения (nodemailer)
- Вход по email/паролю
- Гостевой вход (анонимный пользователь — может читать чаты, но не писать)
- Восстановление пароля через email
- JWT-токены, хранение в `localStorage`
- Профиль: изменение имени, загрузка аватара, выбор seed-аватара (генеративный)

### Книжная полка (ShelvesTab)
- Полки: «Новые», «Хочу прочитать», «Читаю», «Прочитано», «Любимые»
- Поиск книг по названию/автору через внешние источники
- Добавление книги на любую полку
- Просмотр деталей книги в модальном окне

### Вкладка Книга (BookTab)
Блоки в порядке отображения:
1. **Активная книга** — обложка, название, автор, прогресс-бар (прочитано/всего страниц)
2. **Сеанс чтения** — таймер (старт/пауза/сброс), сохранение через скроллируемый PagePicker страниц, кнопка «Я всё прочитал!»
3. **Полки «Хочу прочитать» / «Любимые»** — сетка обложек с Heart-тоглом; нажатие на обложку делает книгу активной
4. **Поиск книги** — поиск по каталогу с добавлением в «Читаю»

### Дневник читателя (DiaryModal)
Открывается модальным оверлеем по «Я всё прочитал!»:
- Выбор формата чтения (бумага/электронная/аудио + тип переплёта)
- Звёздная оценка 1–5
- Поле цитаты и поле заметок
- Слайдеры по критериям: Сюжет, Персонажи, Атмосфера, Романтика, Стекло, Динамика
- Стикеры настроения (slow burn, plot twist, магия и др.)
- Поиск музыки — результаты скрываются сразу после выбора; выбранные треки — список с кнопкой удаления
- Поиск картинок — сетка скрывается после выбора; выбранные изображения с кнопкой удаления
- Сохранение одновременно меняет статус книги на «Прочитано» и создаёт запись в дневнике

### Трекер чтения (TrackersTab)
- Хранение сессий чтения в `localStorage` (`bookvibe_reading_sessions`)
- Статистика: страниц прочитано, время, книги завершены
- Счётчик сессий по датам

### Чаты (ChatsTab)
- 6 жанровых комнат: Детективы, Фэнтези, Романтика, Стекло, Dark Academia, Рекомендации
- Отправка сообщений только для авторизованных (не гостевых) пользователей
- Polling каждые 5 секунд
- Жалоба на сообщение (кнопка Flag)
- Аватар пользователя рядом с каждым сообщением
- Приветственные сообщения при первом открытии комнаты

### Модерация чатов
- Серверная фильтрация мата (русский + английский через `bad-words` + ручной список)
- Действия: `replace` (замена на ***) или `block` (отклонение сообщения)
- Логирование нарушений в `moderation_logs`
- Блокировка забаненных пользователей на уровне API

### Панель администратора
- Скрытый маршрут: `/admin-panel-secret-777`
- Вход по паролю (`ADMIN_PASSWORD` из env)
- Управление пользователями (бан/разбан)
- Просмотр и удаление сообщений по каждой комнате
- Просмотр логов модерации

### Профиль (ProfileTab)
- Имя, email, аватар
- Статистика чтения (книги, страницы, время)
- Лента записей дневника с детальным просмотром
- Сброс статистики
- Экспорт записи в PDF + скриншот (html2canvas + jspdf)

### Прочее
- 4 темы оформления: Academia, Romance, Forest, Contrast
- Мультиязычность (ru/en) через `useLanguage` hook
- Поиск музыки через `/api/music/search`
- Поиск изображений через `/api/images/search`
- AI-помощник для дневника через `/api/ai/diary-helper`

## API Endpoints

Все маршруты доступны через `/api/...`

### Аутентификация
| Метод | Путь | Описание |
|---|---|---|
| POST | `/auth/register` | Регистрация + отправка кода на email |
| POST | `/auth/verify` | Подтверждение email по коду |
| POST | `/auth/login` | Вход по email/паролю → JWT |
| POST | `/auth/guest` | Гостевой вход → JWT |
| POST | `/auth/profile` | Обновление профиля (требует JWT) |
| POST | `/auth/forgot-password` | Запрос сброса пароля |
| POST | `/auth/reset-password` | Установка нового пароля по токену |

### Книги
| Метод | Путь | Описание |
|---|---|---|
| GET | `/books` | Список книг текущего пользователя |
| POST | `/books` | Сохранить/обновить книгу (id в теле = update) |
| DELETE | `/books/:bookId` | Удалить книгу |
| GET | `/books/search?q=&limit=` | Поиск по внешним каталогам |

### Дневник
| Метод | Путь | Описание |
|---|---|---|
| GET | `/diary` | Все записи дневника пользователя |
| POST | `/diary` | Создать/обновить запись дневника |

### Чаты
| Метод | Путь | Описание |
|---|---|---|
| GET | `/chats/rooms` | Список комнат с последним сообщением и счётчиком |
| GET | `/chats/:roomId/messages?limit=` | Сообщения комнаты (по умолчанию 40) |
| POST | `/chats/:roomId/messages` | Отправить сообщение (требует JWT не-гостя) |
| POST | `/chats/:roomId/messages/:messageId/report` | Пожаловаться на сообщение |

### Медиа и поиск
| Метод | Путь | Описание |
|---|---|---|
| GET | `/music/search?q=&limit=` | Поиск музыки |
| GET | `/images/search?q=&limit=` | Поиск изображений |

### Прочее
| Метод | Путь | Описание |
|---|---|---|
| GET | `/ratings` | Рейтинги книг |
| POST | `/ai/diary-helper` | AI-помощник для заметки в дневник |
| GET | `/healthz` | Health check |
| POST | `/stats/reset` | Сброс статистики чтения пользователя |

### Панель администратора (требует `ADMIN_PASSWORD` в теле POST `/admin/login`)
| Метод | Путь | Описание |
|---|---|---|
| POST | `/admin/login` | Получить admin-токен |
| GET | `/admin/users` | Список всех пользователей |
| POST | `/admin/users/:id/ban` | Бан/разбан пользователя |
| GET | `/admin/chats/:roomId/messages` | Все сообщения комнаты |
| DELETE | `/admin/messages/:id` | Удалить сообщение |
| GET | `/admin/moderation-logs` | Логи автофильтра |

## Переменные окружения

Устанавливаются в Replit Secrets (или файл `.env` — **не коммитить!**)

```
DATABASE_URL=          # PostgreSQL connection string (предоставляется Replit автоматически)
JWT_SECRET=            # Секрет для подписи JWT-токенов
ADMIN_PASSWORD=        # Пароль для входа в /admin-panel-secret-777
SMTP_HOST=             # SMTP-сервер для отправки кодов подтверждения
SMTP_PORT=             # Порт SMTP (обычно 587 или 465)
SMTP_USER=             # Логин SMTP
SMTP_PASS=             # Пароль SMTP
SMTP_FROM=             # Email отправителя ("BookVibe <noreply@...>")
OPENAI_API_KEY=        # Для AI-помощника дневника (опционально)
PORT=                  # Назначается Replit автоматически (api-server = 8080)
```

## Запуск

На Replit оба воркфлоу запускаются автоматически. Для локального запуска:

```bash
pnpm install

# API-сервер (порт 8080)
pnpm --filter @workspace/api-server run dev

# Фронтенд (порт 22200)
pnpm --filter @workspace/bookvibe run dev
```

Миграции БД применяются автоматически при старте сервера.

### Регенерация API-клиента
При изменении OpenAPI-спецификации (`lib/api-spec`):
```bash
pnpm --filter @workspace/api-spec run codegen
```

## Ключевые технические детали

### Авторизация
- JWT в заголовке `Authorization: Bearer <token>`
- Токен: `localStorage['bookvibe_token']`
- Данные пользователя: `localStorage['bookvibe_user']`
- Гостевые пользователи: `isAnonymous: true` — читают чаты, но не пишут

### Локальное состояние (localStorage)
| Ключ | Содержимое |
|---|---|
| `bookvibe_token` | JWT-токен |
| `bookvibe_user` | JSON объект пользователя |
| `bookvibe_active_book` | ID активной книги (число) |
| `bookvibe_tab` | Последняя активная вкладка |
| `bookvibe_theme` | Тема оформления |
| `bookvibe_reading_timer_running` | `"true"` / `"false"` |
| `bookvibe_reading_timer_seconds` | Накопленные секунды таймера |
| `bookvibe_reading_timer_updated_at` | Unix timestamp последнего обновления |
| `bookvibe_reading_sessions` | JSON массив сессий чтения |
| `bookvibe_book_meta_<id>` | `{format, binding}` для конкретной книги |

### Прокси и маршрутизация (Replit)
- `/api/*` → порт 8080 (api-server)
- Всё остальное → порт 22200 (bookvibe фронтенд)
- Панель администратора: `/admin-panel-secret-777` — обрабатывается фронтендом

## Известные особенности

1. **Гостевые книги** — книги гостей сохраняются с `user_id = null`; при регистрации они не мигрируют автоматически
2. **PDF-экспорт** — `html2canvas` + `jspdf`; на некоторых мобильных может быть медленным
3. **Чаты без пагинации** — загружаются последние 40 сообщений; при большом объёме нужна пагинация
4. **Email без SMTP** — без настройки SMTP регистрация упадёт с ошибкой
5. **AI-помощник** — без `OPENAI_API_KEY` эндпоинт вернёт 500; обработать gracefully на фронте
